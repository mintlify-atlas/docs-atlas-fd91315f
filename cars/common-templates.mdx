The `config/cars/common/` directory ships with CSP and contains reusable INI fragments that cover the most common lighting rigs, material presets, and feature setups. Rather than copy-pasting dozens of lines into every car config, you reference these files with an `[INCLUDE]` directive and then override only the parameters that differ for your specific car.

---

## Using the INCLUDE Directive

There are two equivalent syntaxes. The bracket form is preferred for clarity:

```ini
; Bracket form (recommended)
[INCLUDE: common/selflighting.ini]

; Legacy key-value form (also supported)
[INCLUDE]
INCLUDE = common/selflighting.ini
```

After the include you can follow it immediately with section overrides. Parameters you set in those override sections take precedence over the defaults declared inside the included file.

```ini
[INCLUDE: common/materials_carpaint.ini]
CarPaintMaterial    = EXT_Carpaint
CarPaintVersionAware = 4
DisableDev          = 1

; Override one sub-template from inside the included file
[Material_CarPaint_Solid]
PROP_... = extExtraSharpLocalReflections, -0.001
```

## Detailed Examples

### selflighting.ini — Headlight Self-Illumination

The self-lighting template creates short-range extra lights at the headlight positions so the car body glows when headlights are on. The template defaults are sensible; you only need to set `POSITION`, `MIRROR`, and `BOUND_TO` for your specific car.

```ini
[INCLUDE: common/selflighting.ini]

; Override the headlight self-light for the RUF Yellowbird
[SelfLight_Headlights]
POSITION              = 0, 0.64, 1.76
MIRROR                = 0.618
DIRECTION             = 0, 0.3, 1
AFFECTS_TRACK         = 0
DIFFUSE_CONCENTRATION = 1
BOUND_TO              = Light_Front
SPOT_SHARPNESS        = 0.5
SPOT                  = 160
COLOR                 = 10
SPECULAR_MULT         = 0
RANGE                 = 0.5
```

The template's built-in defaults already set `SELF_LIGHTNING = exterioronly`, `FADE_AT = 10`, `FADE_SMOOTH = 10`, `SPOT = 190`, `RANGE = 0.5`, and a few others, so you only override what differs.

### gt3_lights.ini — GT3 Interior Cockpit Glow

Including this file adds a single blue-tinted extra light that activates with the headlight switch, casting ambient cockpit illumination typical of modern GT3 cars:

```ini
[INCLUDE: common/gt3_lights.ini]

; Optionally override the defaults
HeadlightsMesh     = head_lights
InteriorLightColor = #3333ff
InteriorLightDiffuse = 10
InteriorLightSpecular = 3
InteriorLightPos   = 0.2, 1.0, -0.4
```

The generated light uses `AFFECTS_TRACK = INTERIOR_ONLY` — a special CSP value that restricts the light to interior meshes and prevents it from illuminating the car exterior or road.

### Full Car Example — BMW M3 E30

The BMW M3 E30 config demonstrates typical multi-include usage combining popup light suppression, carpaint, glass, licence plate lighting, and interior materials:

```ini
; Suppress the factory popup light animation
[INCLUDE]
INCLUDE = common/no_popup_lights.ini

; Car paint — metallic variant, version 4 defaults
[INCLUDE: common/materials_carpaint.ini]
CarPaintMaterial     = Carpaint
CarPaintVersionAware = 4
DisableDev           = 1

[Material_CarPaint_Metallic]
; No extra overrides needed — defaults look great

; Exterior glass
[INCLUDE: common/materials_glass.ini]
ExteriorGlassMaterials = Glass

; European-style licence plate lighting
[INCLUDE: common/materials_license_plate.ini]
[Material_LicensePlate_Europe]

; Interior PBR surfaces
[INCLUDE: common/materials_interior.ini]
```

### Full Car Example — RUF Yellowbird

The Yellowbird uses selflighting, carpaint, glass (with mask pass for tint), licence plate, and interior includes all together:

```ini
[INCLUDE: common/selflighting.ini]

[SelfLight_Headlights]
POSITION  = 0, 0.64, 1.76
MIRROR    = 0.618
DIRECTION = 0, 0.3, 1
BOUND_TO  = Light_Front
SPOT      = 160
COLOR     = 10
RANGE     = 0.5

[INCLUDE: common/materials_carpaint.ini]
CarPaintMaterial     = EXT_Carpaint
CarPaintVersionAware = 4
DisableDev           = 1

[Material_CarPaint_Solid]
PROP_... = extExtraSharpLocalReflections, -0.001

[INCLUDE: common/materials_glass.ini]
[Material_Glass]
Materials = EXT_Glass
FilmIOR   = 2.2
MaskPass  = 1

[INCLUDE: common/materials_license_plate.ini]
[Material_LicensePlate_Europe]
LightLayout = AT_SIDES

[INCLUDE: common/materials_interior.ini]
```

<Note>
  All paths in `[INCLUDE]` are relative to the `config/cars/common/` directory. You do not need to specify the full path — `common/selflighting.ini` is sufficient from any car config file.
</Note>
