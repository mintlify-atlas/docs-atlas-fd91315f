The Custom Shaders Patch (CSP) extends Assetto Corsa's car system through INI configuration files that live inside both the game installation tree and your Documents folder. Each file maps one-to-one to a car folder and can override lighting, materials, instruments, mirrors, and a wide range of visual features — all without touching the original KN5 asset. Changes are picked up immediately when the file is saved while AC is running, making iteration fast and painless.

## File Placement

Config files are grouped into three directories under `assettocorsa/extension/config/cars/`:

| Directory | Purpose |
|---|---|
| `kunos/` | Official Kunos Simulazioni cars (bundled with the game) |
| `mods/` | Community and third-party mod cars |
| `common/` | Shared include files — templates and helpers reused across many cars |

## File Naming

Each INI file must match the car's folder name inside `assettocorsa/content/cars/`. For example, the car stored in `content/cars/bmw_m3_e30/` is configured by `extension/config/cars/kunos/bmw_m3_e30.ini`.

```ini
; assettocorsa/extension/config/cars/kunos/bmw_m3_e30.ini
[LIGHTING]
EMISSIVE_HEADLIGHTS_MULT = 3
EMISSIVE_BRAKELIGHTS_MULT = 0.2
```

## Guessed Config Workflow

CSP can auto-generate a starting-point config for any car by reading its `data/lights.ini` file. This saves time when adding support for a mod car from scratch.

<Steps>
  <Step title="Create the trigger directory">
    Create the folder `%USERPROFILE%\Documents\Assetto Corsa\cfg\extension_cars_guessed\` if it does not exist.
  </Step>
  <Step title="Run Assetto Corsa with the target car">
    Load any session with the car you want to configure. CSP will detect the trigger folder and write a guessed config named `<car_folder_name>.ini` into it.
  </Step>
  <Step title="Copy the guessed config to the extension directory">
    Move or copy the generated file to `%USERPROFILE%\Documents\Assetto Corsa\cfg\extension\config\cars\` (inside an appropriate subdirectory such as `mods/`).
  </Step>
  <Step title="Edit and refine">
    Open the file in a text editor. Save it while AC is running to see most changes reflected immediately in-game via live reload.
  </Step>
</Steps>

<Note>
  Not every section supports live reload. Light positions, shader replacements, and instrument settings reload correctly; changes to `[INSTRUMENTS]` odometer layout take effect after the session restarts.
</Note>

## Live Reload

CSP watches the config file's modification timestamp. Save the INI while a session is running and most visual changes — emissive colours, light intensities, bounced light parameters — update on the fly. This allows side-by-side editing in a text editor while watching the car in the free-camera view.

## Available Config Sections

The table below lists the most commonly used top-level sections. Section and value names containing `_X` accept a zero-based numeric suffix (`_0`, `_1`, …, `_15`), allowing multiple instances of the same section type.

| Section | Description |
|---|---|
| `[BASIC]` | Fundamental car flags: bounding sphere radius, brake threshold, engine-stalled RPM, open-wheeler mode, turning-light repeat behaviour |
| `[LIGHTING]` | Global emissive multipliers for headlights, brake lights, parking lights, and interior shadow intensity |
| `[LIGHT_HEADLIGHT_X]` | True dynamic headlight that casts shadows and illuminates the road; supports spot shape, colour, range, popup animation, and secondary beam |
| `[LIGHT_BRAKE_X]` | Dynamic brake-light source behind the car with on/off colour states and fade-by-distance |
| `[EMISSIVE_LIGHT_X]` | Makes a named mesh glow like a headlight without casting a dynamic light; useful for DRL and running-light strips |
| `[EMISSIVE_BRAKE_X]` | Emissive mesh that lights up when brakes are applied; supports off-colour for tail-light dim state |
| `[BOUNCED_BRAKE_LIGHTS]` | Fake volumetric "ground bleed" behind the brake lights — a gradient projected onto the road surface |
| `[BOUNCED_HEADLIGHTS]` | Same ground-bleed effect applied to the front headlights |
| `[SMART_MIRROR]` | Controls which interior mirror reflections are rendered in first-person view |
| `[INSTRUMENTS]` | Speed-needle lag, speedometer maximum reading, fuel-splash multiplier, and hazard-light G-threshold |
| `[DEFORMING_HOOD]` | Procedural hood bulge animation driven by engine speed noise |
| `[SHADOWED_WHEELS]` | Projected circular shadow underneath each wheel to fake contact AO at a distance |
