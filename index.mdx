The **Custom Shaders Patch Extension Config** repository contains every INI configuration file, Lua script, and texture resource that the [Custom Shaders Patch (CSP)](https://acstuff.club/patch/) loads to deliver enhanced lighting, dynamic weather, PBR materials, and physics-accurate visual effects inside Assetto Corsa. If you want to add lights to a modded car, configure night-time track illumination, script a weather controller, or tweak post-processing, this is the place to start.

## How It Works

CSP reads configuration from `assettocorsa/extension/` on startup and watches for live changes while the game is running. This repo is the canonical source for those configs — Content Manager pulls it automatically, or you can clone it and drop files directly into your AC installation.

<Steps>
  <Step title="Install Custom Shaders Patch">
    Download CSP from [acstuff.club/patch](https://acstuff.club/patch/) and install it via Content Manager or manually by placing `dwrite.dll` next to `acs.exe`.
  </Step>
  <Step title="Get the extension configs">
    Content Manager downloads configs automatically. For manual installs, clone this repository and copy its contents so that `extension/config/`, `extension/textures/`, and `extension/vao-patches/` land under your `assettocorsa/` root.
  </Step>
  <Step title="Edit configs live">
    Most INI settings take effect immediately when you save the file — no restart required. Car and track configs can be edited while AC is running for rapid iteration.
  </Step>
  <Step title="Contribute your changes">
    Open a pull request on GitHub to share your car lights, track configs, or Lua scripts with the community.
  </Step>
</Steps>
